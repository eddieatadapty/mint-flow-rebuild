# Mint Growth Audit

**Live → https://eddieatadapty.github.io/mint-flow-rebuild/**

Five ideas to turn more Mint users into subscribers, each built into a clickable version of Mint's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | Ask what they follow on the first open, then sell that | +10–15% CR to purchase |
| 02 | Show one full stock pick before the price | +5–15% CR to purchase |
| 03 | Make the yearly price add up | +5–15% ARPU |
| 04 | Offer WSJ or The Economist after the choice | +5–10% ARPU |
| 05 | Answer ✕ with six months | +5–10% CR from paywall closers |

Every price, rating and feature comes from Mint's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for Mint. They overlap, so they don’t add up.

Static single page, no build step: `python3 -m http.server`.
